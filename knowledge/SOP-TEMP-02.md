# Temperature drift 溫度飄移

## Confirm and compare / 確認與比對
SYNTHETIC DEMO PROCEDURE. For oven temperature drift above 10 C from target, hold the simulated lot for review. Compare the sensor with an independent calibrated reference and review calibration history. Overdue calibration is an unconfirmed hypothesis. Notify the process on-call engineer. Do not automatically change the setpoint or assert the lot is safe.

## Recovery evidence / 復原證據
Record the target, actual reading, calibration due date and engineer findings. An authorized engineer signs off before simulated lot release. Include missing reference readings as an uncertainty in the incident handover.
